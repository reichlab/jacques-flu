# Influenza burden estimates

Estimates of seasonal influenza burden were taken from
https://www.cdc.gov/flu/about/burden/past-seasons.html on November 27, 2024 and
saved in the file `data/raw/burden-estimates/burden-estimates.csv`. Estimates were taken from the second plot on https://www.cdc.gov/flu-burden/php/about/index.html.
